# Channels · stella.casa

Editable HTML templates (with their PNG exports) for the stella.casa communication channels. Each file is a standalone page, sized exactly to the stated format, that links `../tokens.css` for colors and fonts. To edit a file: open the HTML, change the texts/placeholders, re-export the screenshot at the same viewport size.

## Files

- **instagram-story.html**: 1080×1920 px. Instagram story. Family A illustration (silhouette and light) full bleed, with 220 px free at the top and 260 px at the bottom for the app interface. Cream box with the message "Prima di affidarla, conosciamola." and CTA "Link nella story".

- **instagram-carousel-01.html / -02.html / -03.html**: 1080×1350 px each. Three-slide Instagram carousel "Un preventivo da leggere": 01 question cover (Corallo background, Prugna title), 02 explanation (Crema, three items: Compenso / Base di calcolo / Costi esclusi, no amounts), 03 action (Vino, cream text, CTA "Leggi la guida su stella.casa/diario"). Numbering 1/3–3/3 and symbol at the top of every slide.

- **email-signature.html**: 600×220 px. Horizontal email signature: signature logo, placeholder name/role, placeholder phone/email, site reference. No images besides the logo.

- **poster.html**: 1123×1587 px (A3 portrait). Paper poster: family A illustration in the top 60%, title "La tua casa, seguita da vicino.", one subtitle line, stacked logo, placeholder contact.

- **welcome.html**: 874×1240 px (A5 portrait). Welcome card for the guests of Stella sul Mare: welcome message, Wi-Fi / check-out / contact information (labelled "esempio"), closing line "Una casa seguita da stella.casa" with the signature logo.

- **notebook.html**: 1240×1754 px (A4 portrait). Operating document for the owner ("Quaderno della casa · esempio"): header with signature logo and a small family B illustration, house/period/author fields, interventions table (Data · Voce · Stato · Nota) with statuses written in words ("Da verificare", "Completato") as well as in color. No illustration inside the table.

## Notes

- All price, contact, date and number values are placeholders labelled "esempio": they do not represent real stella.casa data.
- Family A illustrations (silhouette and light) and family B illustrations (detail engraving) never appear in the same block.
- Every exported PNG has the same name as the matching HTML file, in the same folder.
